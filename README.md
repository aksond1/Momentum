# Momentum

Momentum is a personal productivity and self-tracking application written in Java.

The project is designed to help track different aspects of everyday life, including habits, tasks, time, experiments, thoughts, and personal statistics.

> **Status:** Early development

## Project Goals

Momentum is primarily a learning and experimentation project.

The main goal is to practice Java by gradually building a real application while exploring software design, databases, persistence, and other technologies.

## Development

The project is currently under active development. Features, architecture, and the database structure may change significantly as the project evolves.
